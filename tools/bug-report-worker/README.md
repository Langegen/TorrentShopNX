# Сервер отчётов об ошибках

Небольшой Cloudflare Worker для кнопки «Отправить разработчику»
(Настройки → «Отчёт об ошибке»). Приложение отправляет на него ZIP с логами,
а он пересылает архив в ваш закрытый Telegram-чат с подписью:

```
🐞 R-7F3A2C от @username
TorrentShopNX 2.21 · FW 23.0.1 · ru · RU
Прошлый запуск: unexpected · 84 КБ

<описание проблемы от пользователя>
```

`@username` — Telegram, который пользователь указал в настройках отчёта
(необязательно). По нему можно написать человеку. Код отчёта пользователь
видит после отправки и может написать его в теме ошибок
(https://t.me/TorrentShopNX/553), чтобы вы сопоставили сообщение с архивом.

Второй способ, без сервера, — «Отправить самому через телефон»: пользователь
сканирует QR, скачивает архив на телефон и сам прикрепляет его в теме ошибок.
Он работает, даже если сервер не настроен.

Токен бота хранится только в секретах Cloudflare, в приложение он не попадает.
Бесплатного тарифа Workers хватает с запасом.

## Настройка (один раз)

1. **Бот.** В Telegram откройте @BotFather → `/newbot` и сохраните токен.
2. **Чат для отчётов.** Создайте закрытую группу (или используйте личный чат
   с ботом), добавьте туда бота и напишите любое сообщение. Не используйте
   публичную группу: в логах видно, какие игры качал пользователь.
   Затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
   `"chat":{"id":...}`. У групп id отрицательный, например `-1001234567890`.
   Если группа с темами, id темы можно указать в `wrangler.toml`
   (`TELEGRAM_THREAD_ID`).
3. **Деплой.** Нужен Node.js 18+. В этой папке выполните:

   ```bash
   npx wrangler login
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put TELEGRAM_CHAT_ID
   npx wrangler deploy
   ```

   `deploy` напечатает адрес вида `https://tsnx-reports.<ваш-поддомен>.workers.dev`.
4. **Проверка.** Отправьте любой ZIP:

   ```bash
   curl -X POST -H "X-TSNX-Version: test" -H "X-TSNX-Contact: %40durov" --data-binary @test.zip https://tsnx-reports.<поддомен>.workers.dev/v1/report
   ```

   В ответ придёт `{"ok":true,"id":"R-..."}`, а архив появится в чате.
5. **Адрес в приложении.** Впишите `https://.../v1/report` в `TSNX_REPORT_URL`
   в `source/utils/bug_report.cpp` и пересоберите приложение. Пока адрес
   пустой, кнопка «Отправить разработчику» скрыта, а остальные способы
   работают. В PC-сборке адрес можно подставить без пересборки, через
   переменную окружения `TSNX_REPORT_URL`.

## Ограничения

- Не больше 3 отчётов в минуту с одного IP и 30 в минуту всего
  (`[[ratelimits]]` в `wrangler.toml`). Размер архива — до 10 МБ.
- Принимается только ZIP с заголовком `X-TSNX-Version`.
- **Доступность из России.** С 2025 года российские провайдеры замедляют
  соединения с Cloudflare, и загрузка архива на 100–300 КБ может не пройти.
  Проверьте отправку с консоли из России. Если не проходит, этот же протокол
  можно поднять на другом хостинге: логика целиком в `src/index.js`.
  Если отправка не удалась, приложение предлагает отправить отчёт через телефон.

## Протокол

`POST /v1/report`, тело — ZIP.

| Заголовок | Значение |
|---|---|
| `X-TSNX-Version` | версия приложения (обязателен) |
| `X-TSNX-Firmware` | прошивка консоли или `pc` |
| `X-TSNX-Lang` | язык интерфейса |
| `X-TSNX-Prev` | как завершился прошлый запуск: `clean`, `fatal`, `unexpected`, `none` |
| `X-TSNX-Contact` | Telegram пользователя `@username` в percent-encoding, может быть пустым |
| `X-TSNX-Message` | описание проблемы в percent-encoding, до 600 символов |

Ответы: `200 {"ok":true,"id":"R-XXXXXX"}`; ошибки — `{"ok":false,"error":...}`
с кодами `400 bad_request/not_a_zip`, `413 too_large`, `429 rate_limited`,
`500 server_not_configured/internal_error`, `502 delivery_failed`.
