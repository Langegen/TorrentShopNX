**TorrentShopNX** — это универсальное и многофункциональное homebrew-приложение для Nintendo Switch, объединяющее обширный каталог игр, полноценный встроенный BitTorrent-клиент, модуль прямой потоковой установки, каталог ретро-игр для 20 платформ, менеджер эмуляторов и двухпанельный файловый менеджер с архиватором. С ним можно находить, скачивать и устанавливать игры, обновления, DLC и ретро-ромы прямо на консоль без необходимости использовать компьютер и внешние серверы.

> [!IMPORTANT]
> **Внимание!** Проект создан исключительно в ознакомительных и исследовательских целях. Используйте приложение только с тем контентом, на который у вас есть законные права.

## ✨ Ключевые возможности

- ⚡ **Встроенный BitTorrent-движок (Custom Engine)**:
  - Полностью автономен — работает прямо на Switch, не требуя внешних серверов и запущенного ПК.
  - Поддержка современных протоколов: DHT (Kademlia), µTP, PEX, UDP/HTTP(S)-трекеры, быстрый обмен метаданными через magnet (BEP 9 / ut_metadata).
  - Интеллектуальный планировщик кусков (Piece Picker) со скользящим буфером предзагрузки для непрерывного стриминга в память.
  - Высокая стабильность и скорость: оптимизированная ротация choke/unchoke, поддержка крупных раздач с размером кусков 16 МБ без просадок скорости.
  - **Swarm Inspector**: мониторинг состояния подключенных пиров, сидов и скорости роя в реальном времени.
  - Настройка входящего порта (по умолчанию TCP `6882`) для максимизации доступных пиров при прямом соединении.

- 🎮 **Прямая потоковая установка на лету (Stream Installer)**:
  - Установка NSP, NCZ, XCI, обновлений и DLC напрямую в память консоли (SD-карту или системную память NAND).
  - **FAT32-friendly**: не требует предварительного скачивания огромных файлов архивов (20–40+ ГБ) на карту памяти, экономя ресурс SD и свободное место.
  - **Проверка совместимости системного ПО (SDK Mismatch Check)**: предупреждение, если для запуска игры требуется более новая версия Horizon OS, чем установлена на консоли.
  - **Расчёт размера распаковки**: предварительный расчёт реального распакованного размера сжатых пакетов (NSZ/NCZ) перед началом установки.

- 🕹️ **Каталог ретро-игр, ROM'ов и менеджер эмуляторов**:
  - Огромная база: более **8 200+ игр для 20 платформ**:
    - **Nintendo (10 систем)**: NES / Famicom, Super Nintendo (SNES), Nintendo 64, Game Boy / Color, Game Boy Advance, Nintendo DS, Nintendo 3DS, GameCube, Wii, Wii U.
    - **Sony (4 системы)**: PlayStation 1, PlayStation 2, PlayStation Portable (PSP), PlayStation Vita.
    - **Sega (6 систем)**: Mega Drive / Genesis, Master System, Game Gear, Dreamcast, Saturn, SG-1000.
  - Включает оригинальные дампы, качественные русификации и популярные фанатские хаки.
  - **Менеджер эмуляторов и BIOS**: загрузка и обновление автономных эмуляторов (RetroArch, pSNES, mGBA, PPSSPP и др.) и необходимых файлов BIOS в один клик.
  - **Древовидный проводник (Folder Tree Explorer)**: навигация по папкам внутри раздач ромсетов без лимита на количество файлов (снято ограничение в 256 файлов) с возможностью выборочной загрузки.
  - Автоматическое сохранение в папку эмуляторов (по умолчанию `sdmc:/roms/<консоль>/`) или пользовательский путь.
  - Онлайн-обновление баз ретро-игр напрямую с GitHub по нажатию кнопки `-`.

- 🗂️ **Встроенный двухпанельный файловый менеджер и утилиты**:
  - Быстрый доступ по нажатию кнопки `+` с любого экрана приложения.
  - **Двухпанельный режим (Split Screen)**: быстрое переключение по кнопке `-` для удобного просмотра двух папок и мгновенного копирования/перемещения файлов.
  - **Архиватор (7zsdk)**: потоковая распаковка `.7z`, `.zip`, `.rar` с наглядным прогрессом, а также создание архивов `.zip` прямо на Switch.
  - **Установщик пакетов**: установка NSP, NSZ, XCI, XCZ прямо из локальной файловой системы.
  - **Встроенный просмотрщик текстов (Text Viewer)**: чтение NFO, инструкций и текстовых документов.
  - Групповые операции над файлами: мультивыбор по `Y`, выбор всех файлов по `LB`, снятие выделения по `RB`.
  - Быстрое открытие папки завершенных неигровых загрузок в файловом менеджере по кнопке `A`.

- 🎨 **Темы оформления и кастомизация интерфейса**:
  - Светлая тема по умолчанию (Default Light Theme), темная тема и 6 стильных цветовых палитр: Emerald, Amber, Amethyst, Cyberpunk, Graphite, Ruby.
  - Поддержка собственных обоев (Wallpapers): предустановленные тематические фоны или любое пользовательское изображение с SD-карты.
  - Тонкая настройка размытия (Blur: 0–3) и затемнения (Dim: 0–4) фона для лучшей читаемости текста.
  - Возможность скрыть нижнюю информационную панель дашборда для минималистичного вида.

- 📚 **Богатый каталог игр, поиск и фильтрация**:
  - Встроенные регулярно обновляемые каталоги на русском, английском и других языках.
  - **Дельта-обновления и кэширование по ETag**: мгновенное получение изменений каталога без повторной загрузки всей базы.
  - **Основные разделы**: «Весь каталог» (более 7 000 игр), «Новые релизы», «Топ-100 по версии Metacritic», «Избранное».
  - **14 жанровых и тематических подборок**, алфавитная A-Z навигация и расширенный поиск с экранной клавиатуры.
  - Мультивыбор фильтров (Multi-select) по единой таксономии жанров.

- 🖼️ **Информативные карточки игр**:
  - Обложки высокого качества с локальным кэшированием миниатюр на SD для плавного скролла.
  - Встроенная галерея скриншотов с полноэкранным просмотром.
  - Подробные описания, размер раздачи, информация о языках интерфейса/озвучки и требуемой версии SDK.
  - Система избранного для быстрого доступа к желаемым релизам.

- 📱 **Добавление торрентов по сети (Web UI & QR-код)**:
  - Локальный веб-сервер на Switch (порт `8080`) с отображением QR-кода на экране.
  - Возможность в один клик со смартфона или ПК отправить magnet-ссылку или загрузить `.torrent` файл.

- 🎯 **Выборочная загрузка файлов**:
  - Предварительный просмотр содержимого раздачи с древовидной структурой папок: возможность выбрать только базовую игру, нужный патч или определенные DLC / ромы.

- 📥 **Продвинутый менеджер загрузок**:
  - Отображение прогресса в реальном времени, скорости скачивания, сидов/пиров, текущего этапа (подготовка / стриминг / установка).
  - Приостановка, отмена, Swarm Inspector и управление очередью закачек.

- 💾 **Менеджер игр и мониторинг памяти**:
  - Просмотр установленных игр, версий, установленных DLC и информации о версии SDK.
  - Постоянное отображение занятого и свободного места на SD-карте и системном разделе NAND.

- 🔋 **Энергосбережение и комфорт**:
  - Предотвращение засыпания консоли во время активной загрузки.
  - **Безопасное пробуждение подсветки**: первое нажатие кнопки только включает экран, не вызывая случайных срабатываний элементов меню.
  - Настраиваемый тайм-аут подсветки экрана (Backlight Timeout) для экономии аккумулятора и защиты OLED-экрана.
  - Автоматическое определение режима апплета (Applet Mode) с предупреждением о необходимости запуска через Title Override.

- 🔄 **Встроенное автообновление**:
  - Проверка обновлений приложения с GitHub Releases и обновление в один клик прямо из меню с безопасным применением и перезапуском.

- 🌐 **Альтернативный бэкенд (TorrServer)**:
  - Возможность переключения на удаленный TorrServer в локальной сети, если вы предпочитаете кэширование на домашнем сервере или NAS.

## 🎮 Управление и горячие клавиши

| Кнопка | Действие |
| :---: | :--- |
| **`+`** | Открыть **Файловый менеджер** (из любого экрана) / Начать загрузку (в выборе файлов) / Выход из файлового менеджера |
| **`-`** | **Добавить торрент** по сети (Web UI / QR) / **Обновить базы** (в ретро-играх) / Переключить двухпанельный режим (в файловом менеджере) |
| **`A`** | Выбор / Подтверждение / Открыть папку / Навигация по папкам ромсетов / Открыть загрузку в файловом менеджере |
| **`B`** | Назад / Закрыть диалоговое окно / Отмена |
| **`X`** | Быстрый поиск / Меню действий (в файловом менеджере) / Выбрать всё (в окне выбора файлов) / Обновить дашборд |
| **`Y`** | Мультивыбор фильтров и сортировка / В избранное / Выбор файла (в файловом менеджере) / Менеджер эмуляторов (в ретро-консолях) |
| **`LT` / `RT`** | Переключение между активными панелями (в двухпанельном режиме файлового менеджера) |
| **`LB` / `RB`** | Выбрать всё / Снять всё выделение (в файловом менеджере); перелистывание в галерее скриншотов |

## 🚀 Быстрый старт и установка

### 1. Загрузка
Скачайте последний файл `TorrentShopNX.nro` со страницы [Релизов](https://github.com/Langegen/TorrentShopNX/releases/latest) или воспользуйтесь кнопкой вверху страницы.

### 2. Установка на SD-карту
Скопируйте `TorrentShopNX.nro` на карту памяти по пути:
```text
sdmc:/switch/TorrentShopNX/TorrentShopNX.nro
```

### 3. Запуск приложения

> [!WARNING]
> **Важно: запускайте с полным доступом к памяти (Title Override)!**
> 
> Не запускайте приложение через **Альбом (Applet Mode)** — в этом режиме консоль выделяет всего ~400 МБ оперативной памяти, что приведет к ошибкам нехватки памяти при распаковке и установке игр.
> 
> **Как запустить правильно:**
> 1. Зажмите и удерживайте клавишу **`R`** на контроллере.
> 2. Запустите **любую установленную игру** из главного меню Switch.
> 3. Откроется Homebrew Menu с полным доступом ко всей оперативной памяти (High Memory Mode).
> 4. Запустите **TorrentShopNX**.

## 📱 Добавление раздачи со смартфона или ПК

Если нужной игры нет во встроенном каталоге, вы можете моментально отправить любую раздачу со своего телефона или компьютера:

```text
+-----------------------------------------------------------+
| 1. Нажмите клавишу «-» или откройте раздел «По сети»      |
| 2. Отсканируйте камерой смартфона появившийся QR-код      |
|    (или перейдите по указанному адресу, напр.             |
|     http://192.168.1.50:8080)                             |
| 3. Вставьте magnet-ссылку или выберите .torrent файл      |
| 4. Нажмите «Отправить» — Switch откроет окно выбора файлов|
+-----------------------------------------------------------+
```

## ⚙️ Конфигурация (`config.ini`)

Файл настроек создается автоматически при первом запуске приложения по пути:
```text
sdmc:/switch/TorrentShopNX/config.ini
```

### Пример файла настроек:
```ini
[general]
data_mode=local_client
torrserver_url=http://192.168.1.100:8090
catalog_source_url=https://raw.githubusercontent.com/Langegen/switch-game-collection/refs/heads/main/RU_catalog.json
install_location=auto
keep_awake_during_downloads=true
backlight_timeout=0
cache_cover_thumbnails=false
listen_port=6882
app_update_url=https://api.github.com/repos/Langegen/TorrentShopNX/releases/latest
auto_app_update=true
language=ru

# Настройки каталога ретро-игр
retro_roms_mode=retroarch
retro_custom_path=
retro_auto_extract=false
retro_romset_mode=full

# Внешний вид и темы
theme=light
background_mode=auto
custom_background_path=
background_blur=0
background_dim=2
show_bottom_dashboard=true
```

### Описание параметров:

| Параметр | Возможные значения | Описание |
| :--- | :--- | :--- |
| `data_mode` | `local_client` / `torrserver` | Режим работы: собственный встроенный движок (`local_client`) или внешний TorrServer (`torrserver`). |
| `catalog_source_url` | `http(s)://...` | URL-адрес JSON-каталога игр Switch (если пусто, выбирается автоматически по языку). |
| `install_location` | `auto` / `sd` / `nand` | Место установки игр: автоматически (`auto`), карта памяти (`sd`) или системная память (`nand`). |
| `torrserver_url` | `http(s)://...` | Адрес сервера TorrServer (для режима `data_mode=torrserver`). |
| `keep_awake_during_downloads`| `true` / `false` | Запрещает переход консоли в спящий режим во время активного скачивания. |
| `backlight_timeout` | `0`, `15`, `30`, `60`, `120` | Время в секундах до отключения подсветки экрана (`0` — не отключать). |
| `cache_cover_thumbnails` | `true` / `false` | Кэширование сжатых миниатюр обложек на SD-карту для быстрой и плавной прокрутки. |
| `listen_port` | `1024–65535` (по умолч. `6882`) | Входящий TCP-порт для пиров. Пробросьте этот порт на роутере для максимальной скорости. |
| `auto_app_update` | `true` / `false` | Автоматическая проверка наличия обновлений приложения при запуске. |
| `app_update_url` | `http(s)://...` | API-адрес проверки релизов на GitHub. |
| `language` | `auto` / `ru` / `en` / `es` / `fr` / `de` / `it` / `pt-BR` / `zh-Hans` / `ja` | Язык интерфейса приложения (`auto` — системный язык консоли). |
| `theme` | `light` / `emerald` / `cyberpunk` / `ruby` / `amethyst` / `amber` / `graphite` | Цветовая тема оформления интерфейса (по умолчанию светлая `light`). |
| `background_mode` | `auto` / `custom` / `<theme_name>` | Режим фона: автоматически по теме (`auto`), конкретный арт или пользовательский файл (`custom`). |
| `custom_background_path` | `sdmc:/...` | Путь к собственному изображению обоев на карте памяти (при `background_mode=custom`). |
| `background_blur` | `0` (выкл), `1` (слабый), `2` (средний), `3` (сильный) | Степень размытия фонового изображения. |
| `background_dim` | `0` (0%), `1` (15%), `2` (28%), `3` (45%), `4` (65%) | Степень затемнения фонового изображения для контрастности. |
| `show_bottom_dashboard` | `true` / `false` | Отображение нижней информационной панели статистики дашборда. |
| `retro_roms_mode` | `retroarch` / `downloads` / `custom` | Папка для сохранения ромов: стандартная RetroArch (`sdmc:/roms/<консоль>/`), общая папка загрузок или пользовательская. |
| `retro_custom_path` | `sdmc:/...` | Пользовательский путь для ромов (при `retro_roms_mode=custom`). |
| `retro_auto_extract` | `true` / `false` | Автоматически распаковывать архивы с ромами после загрузки. |
| `retro_romset_mode` | `full` / `select` | Режим загрузки ромсетов: скачивать весь архив целиком (`full`) или открыть древовидный выбор файлов (`select`). |

## 🛠️ Сборка из исходного кода

### Требования:
- Установленный тулчейн [devkitPro](https://devkitpro.org/) (`devkitA64`).
- Библиотеки `libnx`, `switch-curl`, `switch-mbedtls`, `switch-zlib`, `switch-libpng`, `switch-libjpeg-turbo`.
- Исходный код [Borealis](https://github.com/natinusala/borealis) (включен как submodule в `_external/borealis`).

### Сборка:
```bash
# Клонирование репозитория вместе с подмодулями
git clone --recursive https://github.com/Langegen/TorrentShopNX.git
cd TorrentShopNX

# Компиляция проекта
make -j$(nproc)
```

Готовый исполняемый файл:
```text
TorrentShopNX.nro
```

## 📂 Структура проекта

```text
TorrentShopNX/
├── source/
│   ├── 7zsdk/         # Распаковщик архивов (7z, ZIP, RAR)
│   ├── buffer/        # Кольцевой буфер и управление пулом кусков в памяти
│   ├── catalog/       # Менеджер каталога игр, ретро-базы, поиск, подборки
│   ├── config/        # Чтение и запись конфигурации config.ini
│   ├── datasource/    # Модули источников данных (Custom Engine и TorrServer)
│   ├── download/      # Менеджер очереди загрузок и планировщик
│   ├── engine/        # Собственный BitTorrent-клиент (DHT, uTP, Bencode, Wire)
│   ├── installer/     # Потоковый установщик контента (NSP, NCZ, XCI, NCM)
│   ├── net/           # Сетевые утилиты, HTTP-клиент (curl) и локальный Web-сервер
│   ├── rss/           # Парсинг RSS-лент
│   ├── torrent/       # Работа с .torrent файлами и magnet-ссылками
│   ├── ui/            # Пользовательский интерфейс Borealis (экраны, карточки, диалоги)
│   │   └── dashboard/ # Виджеты главного дашборда и статистики
│   └── utils/         # Системные утилиты, логирование, файловые хелперы
├── resources/         # Шрифты, иконки, локализации (i18n), звуки и ассеты RomFS
└── docs/              # Документация, архитектурные планы и скриншоты
    └── screenshots/   # Скриншоты интерфейса приложения
```
