# План: менеджер модов и русификаторов

## Статус (11.11.2026)

Только план, код не менялся. Источники проверены запросами 11.11.2026 (раздел «Источники»).

Требуют решения:
1. Включение и выключение мода без удаления (перенос файлов в хранилище) или только «установить / удалить». В плане — с переносом.
2. Писать ли автору ModCD о доступе к его репозиторию графических модов (этап 7).
3. Русификаторы вне раздач: добавлять в свой индекс только с прямой ссылкой и согласием автора (в плане так) или давать ещё и ссылки «открыть на телефоне».

## Цель

Экран, где для установленной игры видно, какие моды и русификаторы есть, что уже стоит, и где их можно поставить, выключить, обновить и удалить одной кнопкой, не вынимая карту.

## Источники

### 1. Раздачи из каталога (русификаторы)

В `RU_catalog.json` 7300 раздач, у **722** в названии `RUS (Mod.)` или `RUS (Voice Mod.)`: перевод сделан модом. Приложение уже умеет ставить такие файлы в `atmosphere/contents/<tid>/`, но только вместе со всей раздачей.

Что добавить: кнопку «Только русификатор» — качаются одни файлы мода. Игра при этом может быть установлена из другого источника.

Не проверено: у какой доли из 722 перевод лежит отдельными файлами, а у какой вшит в NSP (репаки). Измеряется на этапе 0 по спискам файлов торрентов.

### 2. GameBanana (моды)

Крупнейшая база модов для Switch. API открыт, ключ не нужен. Проверенные адреса (`https://gamebanana.com/apiv11/…`):

| Запрос | Ответ |
|--------|-------|
| `Util/Game/NameMatch?_sName=<название>` | id игры (Tears of the Kingdom → 7617) |
| `Mod/Index?_nPerpage=15&_aFilters[Generic_Game]=<id>&_sSort=Generic_MostDownloaded` | список модов с картинками; у TotK 1705 модов |
| `Mod/Categories?_idGameRow=<id>` | категории с числом модов |
| `Util/Search/Results?_sModelName=Mod&_idGameRow=<id>&_sSearchString=<текст>` | поиск внутри игры |
| `Mod/<id>/ProfilePage` | описание, версия, автор, права (`_aLicenseChecklist`) |
| `Mod/<id>/DownloadPage` | файлы: имя, размер, `_sMd5Checksum`, `_sDownloadUrl`, результат антивируса |

`_sDownloadUrl` (`gamebanana.com/dl/<id>`) отдаёт 302 на `files.gamebanana.com/mods/<файл>`.

Ограничения:
- **Права.** У проверенного мода в `_aLicenseChecklist` запрещено выкладывать файл на других сайтах. Поэтому консоль качает файл прямо с GameBanana, свой индекс хранит только соответствие игр, файлы не зеркалим.
- **Нет Title ID.** Игра в GameBanana — это название, общее для всех платформ (у Hollow Knight, id 8609, моды в основном для ПК). Нужна таблица `Title ID → id игры` с пометкой «только Switch». Её строит сборщик (этап 6).
- **Список файлов до скачивания получить не удалось:** `File/<id>/RawFileList` вернул пустой ответ. Подходит ли архив, узнаём после скачивания (моды обычно небольшие) по оглавлению.
- Лимиты запросов не опубликованы. Консоль ходит в API только по действию пользователя, ответы кэшируются на час.

Образец работы с этим API на консоли — SimpleModDownloader (PoloNX, GPL-3.0, как и TorrentShopNX).

### 3. Чит-коды и патчи графики (60 FPS, разрешение)

| Репозиторий | Что проверено | Формат |
|-------------|---------------|--------|
| `HamletDuFromage/switch-cheats-db` | 426 звёзд, обновлён 17.10.2026 | `versions/<TID>.json`: номер обновления → build ID; `cheats/<TID>.json`: читы по build ID |
| `ChanseyIsTheBest/NX-60FPS-RES-GFX-Cheats` | 899 звёзд, обновлён 07.09.2026 | папка `titles/`, читы 60 FPS и разрешения по играм и build ID |

У обоих репозиториев лицензия не указана: файлы качаем с `raw.githubusercontent.com` по запросу пользователя, к себе не копируем.

### 4. Русификаторы вне раздач

| Где | Проверка | Вывод |
|-----|----------|-------|
| 4PDA, тема «Русификация игр Nintendo Switch» | скрипту отвечает 403; вложения — после входа | автоматически нельзя |
| Playground.ru, раздел «Русификаторы и переводы» | страницы файлов есть, API нет | автоматически нельзя |
| Boosty, Telegram переводчиков | закрытые или платные записи | нельзя |
| GitHub (пример: `nuxdie/overboard-ru`) | релизы с прямыми ссылками | можно, по одному репозиторию |

Общей базы русификаторов с прямыми ссылками не найдено. Решение: свой ручной список в `mods.json` (этап 6) — только записи с прямой ссылкой и согласием автора, в первую очередь релизы на GitHub. Остальное пользователь ставит из своего файла (этап 3).

### 5. ModCD (графические моды с привязкой к версии игры)

`kawaii-flesh/ModCD`, обновлён 02.11.2026, лицензии нет. В таблице модов — сборки ECLIPSE00074 и других с точными версиями игр. Сервер репозитория (`thub.ddns.net:1785/repository.json`) чужому клиенту отвечает 403; автор добавляет моды только с согласия их авторов. Без договорённости не используем.

## Как ставится мод

### Куда можно писать

Строже, чем у хоумбрю (`checkInstallPath` с отдельным набором правил, таблица-тест `pctest/mod_fixtures/path_rules.txt`):

| Путь | Правило |
|------|---------|
| `atmosphere/contents/<TID игры>/romfs/…`, `exefs/…`, `cheats/…`, `romfs.bin` | разрешено; TID должен быть у игры, для которой ставят мод (или её DLC) |
| `atmosphere/exefs_patches/<имя>/<build ID>.ips` | разрешено |
| папки из списка `extra_roots` игры в индексе (Smash: `ultimate/mods/`) | разрешено |
| `atmosphere/contents/<TID>/exefs.nsp`, `flags/`, системный TID (до `01000000000010FF`) | запрещено: это системный модуль |
| всё остальное, включая запреты хоумбрю (`bootloader/`, `..`, корень карты) | запрещено |

Файлы архива вне этих путей (README, картинки) не распаковываются.

### Раскладка архива

`resolveAtmosphereModDest` выносится из `download_manager.cpp` в `source/catalog/mod_layout.*` без изменения поведения и покрывается тестами. Добавляется:
- несколько вариантов в одном архиве (`30FPS/romfs`, `60FPS/romfs`) → выбор варианта;
- в архиве нет ни `romfs`, ни `exefs`, ни Title ID → «мод не для Switch», установка не начинается;
- Title ID в архиве не совпадает с игрой → вопрос (региональные версии).

### Учёт и выключение

- Запись на мод: `data/mods/<TID>/<id>.json` — источник, id в источнике, версия, MD5 архива, список файлов, версия игры при установке, включён ли.
- Установка — как у хоумбрю: файлы пишутся рядом как `.hbnew`, встают на место только когда готовы все; сбой и отмена оставляют карту как была.
- Выключение: файлы мода переносятся в `sdmc:/switch/TorrentShopNX/mods_off/<TID>/<id>/` переименованием (тот же раздел, без копирования). Включение — обратно.
- Конфликт (два мода с одним файлом): предупреждение со списком файлов и выбором. Файл проигравшего мода уходит в его папку в `mods_off`; при удалении победителя возвращается.
- Моды, найденные на карте без записи, показываются как «Установлено вручную» одной строкой; их можно выключить и удалить целиком.
- После обновления игры: у модов с `exefs` и читов, чья версия игры в записи не совпадает с текущей, пометка «Проверьте совместимость». Читы из базы подбираются под новую версию сами.

## Экран

- Вход 1: «Менеджер игр» → игра → «Моды и русификаторы» (сейчас там только размер и удаление).
- Вход 2: вкладка «Моды» в «Менеджере игр»: установленные игры, для которых что-то есть или уже стоит.
- Вход 3: карточка раздачи с `RUS (Mod.)` → «Только русификатор», если игра уже установлена.

Экран игры, вкладки:

| Вкладка | Содержимое | Источник |
|---------|------------|----------|
| Установленные | включить / выключить, обновить, удалить | учёт на карте |
| Русификаторы | текст, озвучка; версия игры, под которую сделан | раздачи каталога, ручной список |
| Моды | категории, поиск, сортировка, карточка со скриншотами | GameBanana |
| Читы и графика | 60 FPS, разрешение, чит-коды под текущую версию | базы читов |

Вкладка без данных для этой игры не показывается.

Внизу экрана — «Установить из файла»: архив из `sdmc:/switch/TorrentShopNX/mods_inbox/` или присланный с телефона через «Добавить по сети» (там уже принимаются .torrent).

## На консоли проверить

1. «Только русификатор» из раздачи для установленной игры; игра запускается на русском.
2. Мод с GameBanana: zip, 7z, rar; архив с вариантами; архив не для Switch.
3. Выключить → игра без мода; включить → с модом. Конфликт двух модов.
4. Читы 60 FPS под текущую версию; обновление игры → читы подобраны заново, у `exefs`-модов пометка.
5. Отмена посреди скачивания и распаковки: в `atmosphere/contents` нет `.hbnew`, `cache/tmp` пуст.
6. Моды, поставленные с ПК, видны как «Установлено вручную», выключаются и удаляются.

## Риски

- GameBanana изменит API или введёт лимиты: вкладка «Моды» показывает ошибку, остальные вкладки работают; адреса API лежат в `mods.json`, их можно поправить без выпуска.
- Мод не под ту версию игры роняет игру при запуске: выключение из менеджера возвращает игру в рабочее состояние; перед установкой `exefs`-модов показываем версию, под которую они сделаны, если она известна.
- Большие моды (Smash, сотни МБ): проверка свободного места до скачивания, архив удаляется после распаковки.
- Вредоносный архив: правила путей выше; `exefs.nsp` и флаги автозапуска мод поставить не может.
