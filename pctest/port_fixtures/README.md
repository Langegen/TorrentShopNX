# Фикстуры планировщика портов

Один файл = одна раздача: список файлов торрента и ожидаемый план установки.
Формат описан в шапке `pctest/test_port_planner.cpp`.

Запуск из корня репозитория:

```
powershell -File pctest\build_port_planner.ps1
```

Источник списка указан в строке `# source:`.

- `log`: список снят с консоли (`grep port_file log.txt | cut -f2-`).
- `описание`: список восстановлен по описанию раздачи. Такие фикстуры стоит
  заменить реальными списками, когда раздача попадёт в лог.
- `синтетика`: искусственный случай для одного правила.

Новая раздача из лога добавляется так:

1. Скопировать строки `port_file` из `log.txt` (после префикса).
2. Добавить `# title:` (строка `PortInstallPlanner: analyzed '...'` в том же логе).
3. Дописать `## expect` с правильными путями по инструкции из раздачи.
